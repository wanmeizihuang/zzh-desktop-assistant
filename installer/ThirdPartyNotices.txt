ZZH Desktop Assistant uses the unmodified LibreHardwareMonitorLib binary as a
separate managed assembly bundled into the self-contained sensor service. The
source code of ZZH Desktop Assistant's own sensor service is included in the
project under services/sensor-service.

Intel Level Zero and NVIDIA NVML are loaded dynamically from installed hardware
drivers when present; their driver binaries are not redistributed by this
installer.

The official, digitally signed PawnIO setup is redistributed unmodified and is
installed as a separate shared driver. It is not removed when ZZH Desktop
Assistant is uninstalled because other hardware-monitoring applications may use
the same driver.
