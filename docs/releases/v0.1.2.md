# ZZH 桌面助手 v0.1.2

首个适合公开验证的 Windows x64 版本，包含动态桌面形象、系统监控、托盘常驻和 AI 模型对话。

## 下载

请下载 `ZZHDesktopAssistant-Setup.exe`。完整安装包包含 ZZH 桌面助手、温度传感器服务，并按需安装官方 PawnIO 2.2.0 驱动。

不建议普通用户下载单独的 `desktop-assistant.exe`：它不包含传感器服务，CPU 或部分 AMD GPU 温度可能不可用。

## 主要功能

- 动态透明桌面形象，支持拖动、置顶、位置锁定、显示/隐藏和托盘操作。
- CPU、内存、GPU、显存、CPU/GPU 温度、网络上下行实时监控。
- 最近 5 分钟趋势曲线和 2/5/10 秒采样频率。
- OpenAI 兼容云端 API、本地模型服务及 Codex CLI 对话。
- API Key 使用 Windows Credential Manager 存储。
- 桌面与 AI 模型配置保存在 `%LOCALAPPDATA%\ZZH Desktop Assistant\settings.json`，并兼容迁移旧目录配置。
- 桌面与开始菜单快捷方式。

## 安装提示

- 支持 Windows 10/11 x64。
- 安装温度服务和 PawnIO 时需要一次管理员确认。
- 当前安装包尚未代码签名，SmartScreen 可能显示提示。请只从本仓库 Releases 页面下载，并核对发布页提供的 SHA-256。
- 卸载助手不会移除共享的 PawnIO 驱动。

## 已知限制

- 不支持文件拖拽给 AI。
- CLI 连接器当前仅支持 Codex CLI。
- 仅显示可信的 CPU Package/Tctl-Tdie 与 GPU Core/Edge 温度；硬件未暴露这些传感器时显示“暂不可用”。
