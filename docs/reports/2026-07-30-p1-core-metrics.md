# P1 核心指标验证报告

日期：2026-07-30
平台：Windows 11 x64，144 DPI（150% 缩放）
数据源：`GetSystemTimes`、`GlobalMemoryStatusEx`、`GetIfTable2`、PDH、DXGI

## 已实现

- CPU 总占用按空闲、内核和用户累计时间做差分。
- 内存显示物理内存使用比例、已用量和总量。
- 网络汇总所有已启用非回环接口的累计字节，并按真实间隔计算上下行速率。
- GPU 利用率按 LUID 和物理引擎汇总进程实例，再取整机最忙引擎。
- 显存通过 PDH 读取系统级专用与共享用量，通过 DXGI 关联硬件适配器及容量。
- 采样在独立线程每 2 秒执行，通过 Slint 事件循环投递快照。
- CPU、网络、GPU 与显存数据源拥有独立状态，单项失败不阻断其他指标。
- 温度不显示推测值，仍明确标记为“待接入”。

## 自动化结果

工作区共 26 个测试通过，其中系统监控包含 12 项测试，覆盖 CPU/网络差分、GPU 引擎聚合、LUID 归一化、多适配器选择、内存与显存比例；桌面 UI 包含 5 项指标格式测试。格式检查与严格 Clippy 均通过。

真实探针连续三次读取均为 `Available`：

```text
CPU：33.3% / 19.0% / 19.6%
物理内存：总量 15.7 GiB，已用约 10.3 GiB
网络：上下行均取得非负速率
GPU：10.1% / 8.1% / 10.0%
总 GPU 内存：已用约 2.05 GiB，总量约 7.99 GiB
```

## UI 与系统对照

监控页快照显示 CPU、内存、GPU、显存和网络实时值，全部在 176 px 卡片内正常显示，无文字溢出或遮挡。截图见 `artifacts/gpu-monitor-panel.png`。

独立 `GPU Adapter Memory` 对照显示主适配器共享用量约 1.5 至 2.1 GiB，应用通过相同系统级 PDH 数据源和 DXGI 容量关联得到约 2.05 / 7.99 GiB，数量级与变化方向一致。本机没有 `nvidia-smi`，未执行 NVIDIA 厂商工具对照。

CPU 和网络对照不是同一采样窗口，后台活动也会改变数值，因此本轮只确认量级和变化行为，不宣称已完成误差验收。P3 会建立同时间窗对照和允许误差。

GPU/显存接入后工作集增加约 8.2 MB、私有内存增加约 6.1 MB，短时数据仍达到 P1 的 50 MB / 0.5% 资源目标，但仍需 24 小时内存趋势和更多硬件场景验证。

## 已知限制

- 当前汇总所有已启用非回环接口，VPN 或虚拟交换机可能与物理网卡重复计数。
- 网络接口切换导致累计值回退时，本周期速率按 0 处理，下一周期自动恢复。
- 尚未实现网卡选择、收起态降频和历史环形缓冲。
- GPU 利用率依赖 Windows GPU Engine 性能计数器，旧驱动或未暴露计数器的设备会独立降级为“不可用”。
- 当前显存卡片展示最活跃硬件适配器的专用与共享 GPU 内存合计；混合显卡切换时容量可能随目标适配器变化。
- 仍需在 NVIDIA、AMD、Intel 独显和无独显设备上建立兼容矩阵。
