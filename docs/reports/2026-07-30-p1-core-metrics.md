# P1 核心指标验证报告

日期：2026-07-30  
平台：Windows 11 x64，144 DPI（150% 缩放）  
数据源：`GetSystemTimes`、`GlobalMemoryStatusEx`、`GetIfTable2`

## 已实现

- CPU 总占用按空闲、内核和用户累计时间做差分。
- 内存显示物理内存使用比例、已用量和总量。
- 网络汇总所有已启用非回环接口的累计字节，并按真实间隔计算上下行速率。
- 采样在独立线程每 2 秒执行，通过 Slint 事件循环投递快照。
- CPU/网络预热及单项数据源失败拥有独立状态，不阻断其他指标。
- GPU、显存和温度不再显示原型数字，统一标记为“待接入”。

## 自动化结果

工作区共 17 个测试通过，其中核心指标包含 CPU 差分、零时间差、网络速率、计数器回退和内存比例 5 项测试；UI 格式包含单位切换、内存文本和不可用状态 3 项测试。格式检查与严格 Clippy 均通过。

真实探针连续三次读取均为 `Available`：

```text
CPU：33.3% / 19.0% / 19.6%
物理内存：总量 15.7 GiB，已用约 10.3 GiB
网络：上下行均取得非负速率
```

## UI 与系统对照

监控页快照显示 CPU 11%、内存 71%（11.2/15.7 GB）、网络下行 7.1 KB/s、上行 11.1 KB/s，全部在 176 px 卡片内正常显示。稍后的独立 WMI 对照显示内存 73.1%（11.5/15.7 GiB），总量一致，使用量变化合理。

CPU 和网络对照不是同一采样窗口，后台活动也会改变数值，因此本轮只确认量级和变化行为，不宣称已完成误差验收。P3 会建立同时间窗对照和允许误差。

## 已知限制

- 网络接口切换导致累计值回退时，本周期速率按 0 处理，下一周期自动恢复。
