# P3 监控核心第三批报告

日期：2026-07-31
范围：采样恢复、数据源错误分类和 Windows 指标对照。

## 实现

- CPU 与网络差分间隔超过 30 秒时丢弃旧基线，下一次采样重新预热。
- 网络累计计数回退或活动网卡集合变化时不计算差分，避免错误尖峰。
- 默认网络范围改为活动物理非回环接口，避免 VPN、隧道和虚拟接口重复累计同一批流量。
- CPU、内存和网络读取失败标记为暂时不可用，并在下一次采样自动重试。
- GPU、显存和温度初始化不存在时标记为不支持；已初始化数据源的一次采样失败标记为暂时不可用。
- 桌面卡片分别显示“不支持 / 当前硬件不支持”和“暂不可用 / 读取失败，将自动重试”。

## 自动化验证

新增单元测试覆盖：

- 30 秒采样间隔边界和超长间隔重建基线。
- 网络计数回退、活动接口集合变化和物理网卡过滤。
- 不支持与暂时错误状态映射。
- GPU 暂时故障及显存不支持的界面文案。

完整质量门禁：

- `cargo clippy --workspace --all-targets --offline -- -D warnings`：通过。
- `cargo build --release -p desktop-assistant --offline`：通过。

## 本机同期对照

环境：Windows 11 x64，使用 `system-monitor` 原生探针与 Windows `Get-Counter` 同期采样三组。WMI/CIM 在当前会话无访问权限，因此未使用其返回的无效零值。

| 指标 | 原生探针 | Windows 性能计数器 | 结论 |
|---|---|---|---|
| 内存使用率 | 79.10%、79.23%、79.41% | 79.09%、79.16%、79.26% | 最大差 0.15 个百分点 |
| CPU 使用率 | 稳定样本 16.44%、20.47% | 邻近样本 19.44%、21.98% | 最大差约 3.00 个百分点 |
| 网络接收 | 1.16-4.81 KB/s | 0.89-2.58 KB/s | 异步窗口量级一致；末组差约 18% |
| 网络发送 | 10.29-33.75 KB/s | 10.13-22.58 KB/s | 异步窗口量级一致；末组差约 1.6% |

CPU 和网络是短周期动态值，两个独立采样器的窗口边界不完全重合，因此不要求逐点相等。物理接口过滤后网络不再出现原先约 5-7 倍的虚拟接口重复累计。
