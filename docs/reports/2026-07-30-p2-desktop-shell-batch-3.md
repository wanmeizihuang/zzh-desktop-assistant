# P2 桌面外壳第三批验证报告

## 范围

- 基于 Slint `SystemTrayIcon` 的 Windows 原生通知区图标。
- 显示/隐藏、展开/收起、始终置顶、锁定位置、设置和退出菜单。
- 托盘左击恢复窗口，设置菜单恢复并直接展开设置页。
- 当前登录会话命名互斥体与自动复位命名事件组成的单实例唤醒通道。
- 托盘、窗口和二次启动入口共享同一个 `WindowState`。

开机启动属于 P2 Task 5。暂停监控需要控制采样 worker，与阈值提醒一起保留在 P6；本批没有暴露不可用的占位菜单项。

## Windows 实机结果

环境为 Windows 11 x64、150% DPI。

| 场景 | 结果 |
|---|---|
| 通知区注册 | UI Automation 识别为 `SystemTray.NormalButton`，名称为“晓曦桌面助手” |
| 原生右键菜单 | 六类动作与分隔结构正确显示 |
| 显示/隐藏 | 隐藏后窗口元素为 0；左击托盘恢复为 300 x 300 物理尺寸 |
| 展开/收起 | 300 x 300 与 618 x 960 物理尺寸正确切换 |
| 设置 | 从托盘恢复、展开并直接打开设置页 |
| 置顶/锁定 | 动作、配置落盘和动态 `✓` 状态标记同步 |
| 第二次启动 | 启动前后均只有原 PID 448；已有窗口收到唤醒 |
| 退出 | 进程数归零，通知区托盘元素归零 |

Slint 1.17.1 的 Windows 托盘后端读取 `checked` 属性但未把它传入原生 `HMENU`。为避免引入第二套托盘运行时，本批使用由同一状态驱动的动态 `✓` 标题表达开启状态。

## 已知限制

- 开机启动、多显示器移除和混合 DPI 热变更恢复属于 P2 Task 5。
- 托盘开关使用动态文本勾选标记，等待 Slint Windows 后端补齐原生 `checked` 标志后可改回标准勾选位。
- P1 的 24 小时内存趋势和 ADR-002 最终闸门仍处于延期状态。
