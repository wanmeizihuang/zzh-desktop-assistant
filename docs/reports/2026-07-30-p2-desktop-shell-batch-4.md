# P2 桌面外壳第四批验证报告

## 范围

- 当前用户开机启动：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。
- 设置页和托盘菜单共享开机启动状态，注册表操作成功后才更新界面。
- Win32 显示器工作区枚举、最近屏幕选择和屏外位置钳制。
- 启动、移动、尺寸和 DPI 事件触发位置复核。
- 通过现有监控线程读取最高有效 ACPI 热区温度，不新增常驻进程或轮询线程。

## 数据语义

温度使用 Windows PDH 的 `Thermal Zone Information` 计数器，优先读取 `High Precision Temperature`，并兼容普通温度计数器。数值经过开尔文转换和 `-50°C..=200°C` 有效范围过滤，多热区取最高值。界面明确标注 `ACPI 热区`，不把它描述为 CPU 核心温度。

## 已知限制

- 当前自动化进程可以启动应用和读取运行指标，但无法把 Slint 工具窗口枚举为交互桌面的顶层窗口。真实多屏热插拔、100%/150% 混合 DPI 和窗口物理落点仍需直接在用户桌面复核。
- ACPI 热区由固件定义，可能代表机身、主板或聚合热区；它不是 CPU 核心温度。没有有效计数器时界面显示不可用。
- 注册表真机往返测试会短暂写入进程专属测试值，因此默认标记为 ignored，并在授权验证时显式运行。
- P1 的 24 小时内存趋势和 ADR-002 最终闸门仍处于延期状态。
