# P3 监控核心第四批报告

日期：2026-07-31
范围：5 分钟趋势序列、Slint 趋势图和可见性更新门控。

## 实现

- 从有界历史生成最多 48 点的趋势序列，在固定绘制成本下覆盖最近 5 分钟。
- CPU 和内存按 0%-100% 归一化并夹取边界值。
- 网络接收与发送采用同一动态量程，便于直接比较两个方向的相对变化。
- 缺失指标保留为缺口，不使用零值填充，避免把不可用误画成空闲。
- Slint 监控页新增 CPU、内存和网络三行点阵迷你趋势图；网络同时显示接收和发送两条序列。
- 趋势模型仅在窗口可见、面板展开且当前为监控页签时更新，避免隐藏状态下无效重绘。
- 指标卡高度压缩为 `82px`，趋势区位于监控内容区内，静态布局边界无重叠。
