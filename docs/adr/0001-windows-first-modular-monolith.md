# ADR-0001：Windows 优先的模块化单体

## 状态

建议接受

## 背景

产品是单机常驻桌面工具，低资源占用和部署简单比独立扩缩容更重要。硬件指标、窗口和凭据接口也具有明显的平台相关性。

## 决策

首期仅支持 Windows 10/11 x64。主程序采用模块化单体；只有温度兼容层和按请求运行的智能体 CLI 使用独立子进程。

## 影响

### 正面

- 单一安装包和主进程，降低内存、IPC 和运维成本。
- 模块边界保留未来的平台适配空间。
- 不稳定的传感器或 CLI 可以与 UI 故障隔离。

### 负面

- macOS/Linux 不能通过重新打包直接支持。
- 主程序模块不能独立部署，但桌面单机产品没有这项需求。

## 备选方案

- 全部单进程：占用最低，但托管传感器库或异常 CLI 会拖垮主程序。
- 本地微服务：隔离性强，但部署、端口、安全和资源成本不合理。
- 首期跨平台：产品覆盖更广，但会显著扩大窗口与传感器适配范围。
