# ADR-0004：使用 Windows Credential Manager

## 状态

已接受并实现

## 背景

应用需要保存多个云端智能体 API Key。本地明文配置、日志和通用数据库都会增加泄漏风险。

## 决策

API Key、访问令牌等秘密存入 Windows Credential Manager。普通配置文件只保存不可用作认证的凭据引用 ID。日志、诊断包和崩溃信息统一执行秘密脱敏。

## 影响

### 正面

- 凭据由系统按当前 Windows 用户保护。
- 配置文件被复制或提交时不会直接泄漏密钥。
- 无需自建主密码和加密密钥生命周期。

### 负面

- 凭据不能随普通配置文件直接迁移。
- 后续跨平台需要分别适配 Keychain 或 Secret Service。

## 备选方案

- 配置文件明文：实现最简单但不可接受。
- 应用自加密：仍需解决加密密钥存放问题，安全收益有限。
- 不保存密钥：安全但严重影响日常使用体验。
