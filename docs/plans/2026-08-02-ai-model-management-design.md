# AI 模型管理设计

日期：2026-08-02
状态：已确认，进入实现

## 目标与边界

设置页新增“AI 管理”入口。用户在弹窗中添加、编辑和删除模型；对话页只选择已经保存的模型，不再理解接口地址、密钥或可执行文件。首版支持三类受管理模型：OpenAI 兼容云端 API、Ollama/LM Studio/vLLM 等 OpenAI 兼容本地服务，以及 Codex CLI。本阶段不直接加载 `.gguf` 等模型文件，也不实现任意 CLI 协议。

## 界面

“AI 管理”使用助手窗口内部的模态层，避免增加独立顶层窗口和任务栏入口。列表页显示模型名称、运行位置、连接方式和配置状态，并提供新增、编辑、删除。编辑页按类型显示字段：

- 云端 API：名称、接口地址、模型 ID、可选 API Key。
- 本地服务：名称、本地接口地址、模型 ID、可选 API Key。
- Codex CLI：名称、可执行文件路径和参数。

API Key 输入框不回填已存明文；空白表示保留，清除密钥使用独立操作。删除模型需要二次确认。配置检查只验证 URL、模型 ID、可执行文件和参数，不自动发送请求或产生云端费用；凭据缺失通过模型列表状态提示。

## 配置与迁移

现有 `AgentProfile` 保持稳定 ID，并为 HTTP 连接增加云端/本地部署标记。显示名称可以修改但不改变 ID、凭据目标或当前选择。新 ID 由程序生成，只使用凭据管理器允许的 ASCII 字符。

配置版本升级后，已有 `agent_profiles` 原样进入管理列表。若首次升级时模型列表为空且检测到 Codex CLI，则生成一个普通、可编辑、可删除的受管理条目，并记录初始化已完成；用户删除后不会在下次启动时重新出现。对话页不再注入配置之外的隐式 Codex 项目。

## 数据一致性与安全

API Key 只写入 Windows Credential Manager，JSON 仅保存凭据引用。新增、替换、清除密钥和删除模型都使用可回滚顺序：先保存旧凭据状态，再执行凭据变化和原子配置保存；任何一步失败时恢复原凭据，且不更新内存模型目录。保存成功后才刷新对话选择。

对话运行时保留历史和请求控制器，只原子替换连接器目录。流式回答期间 AI 管理可以查看，但新增、保存和删除禁用；回答完成或停止后恢复。删除当前模型后选择下一个可用模型，没有模型时对话页显示“请在设置中添加模型”并禁用发送。

## 错误与资源策略

字段错误在编辑页就地显示，保留用户输入。配置或凭据保存失败不关闭弹窗，不显示假成功。HTTP 和 CLI 连接器仍只在发送问题时工作；AI 管理不新增常驻网络任务、模型进程或轮询线程。

## 验证

自动化测试覆盖字段校验、名称和 ID 冲突、配置迁移、Codex 一次性初始化、凭据保留/替换/清除/删除回滚、运行时刷新、删除当前模型和忙碌期只读。完成格式检查、全工作区测试、严格 Clippy 和 Release 构建。弹窗布局、中文输入、增删改和对话选择由用户人工确认，不自动操作桌面界面。
