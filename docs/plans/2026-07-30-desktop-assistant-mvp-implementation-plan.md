# 桌面助手 MVP Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 2026-10-23 前交付一个可安装、可长期驻留的 Windows 桌面助手 MVP，完成低资源硬件监控、多智能体问答和安全文件拖放。

**Architecture:** 使用 Rust 模块化单体和 Slint 原生 UI。基础监控位于主进程；温度兼容层和智能体 CLI 以按需子进程运行；智能体通过能力驱动的统一连接器接入。

**Tech Stack:** Rust stable、Slint、Tokio、windows-rs/Win32、reqwest、serde、tracing、Windows Credential Manager、可选 LibreHardwareMonitor 桥接、cargo-nextest。

## 4. 阶段工作包

### P1：技术验证

**目标：** 在投入完整功能前，验证最难且最影响资源目标的技术假设。

- `apps/desktop/src/main.rs`

- `crates/system-monitor/`
- `crates/agent-core/`
- `crates/agent-http/`
- `crates/agent-cli/`
- `tests/benchmarks/`

**任务：**

- [x] 建立 Rust workspace、格式检查、Clippy 和测试命令。
- [x] 先写窗口状态测试，再实现透明、无边框、置顶、拖动窗口原型。
- [x] 先写指标差分测试，再实现 CPU、内存和网络采样。
- [x] 探测 Windows GPU 利用率和显存数据源，记录当前硬件结果与降级策略。
- [x] 先写连接器契约测试，再实现模拟 HTTP 流和伪 CLI 流。
- [ ] 采集冷启动、工作集、空闲 CPU 和 24 小时内存趋势。
- [ ] 对照 ADR-002 做继续使用 Slint 或回退 WPF 的正式决策。

**2026-07-30 进展：** 窗口、拖动、CPU/内存/网络/GPU/显存原生采样，以及统一智能体契约、模拟 HTTP 流和真实测试子进程 CLI 流均已完成。GPU 与显存接入后的收起态工作集约 30.63 MB、5 秒空闲 CPU 为 0%，详见 `docs/reports/2026-07-30-p1-window-prototype.md`、`docs/reports/2026-07-30-p1-core-metrics.md` 和 `docs/reports/2026-07-30-p1-agent-connectors.md`。

**阶段例外：** 用户于 2026-07-30 决定直接进入 P2。P1 的 24 小时内存趋势未执行，ADR-002 仍保持“待技术验证”，这两项作为已知风险延期到稳定化阶段复核，不计为 P1 已完成。

**闸门：** 收起态核心进程应接近 50 MB、空闲 CPU 平均不高于 0.5%，窗口交互无输入法、DPI 或透明渲染阻断问题。若不通过，先调整技术栈与工期，不进入 P2。

## 6. 进度更新规则

每次完成一个阶段任务后更新本文档，不把“代码已写但未验证”计为完成。

完成定义：

1. 功能代码和对应测试均提交。
2. 格式检查、静态分析和相关测试通过。
3. 可运行演示或可复现命令已提供。
4. 性能敏感功能附资源数据。
5. 已知限制和失败模式已记录。

状态规则：

- `未开始`：尚未产生可验证交付物。
- `进行中`：已有实现，但阶段验收条件未全部通过。
- `受阻`：缺少外部接口、硬件、凭据或产品决策，且模拟方案不能继续降低风险。
- `已完成`：阶段验收条件全部通过。
