# P2 Task 5 与温度检测设计

## 范围

本批完成当前用户开机启动、工作区感知的位置恢复，以及第一种真实温度数据源。开机启动不申请管理员权限；显示器恢复使用任务栏之外的工作区；温度不可用时只降级温度卡片，不影响其他指标。

## 方案选择

开机启动采用 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`。注册表是该设置的唯一事实来源，避免 JSON 与系统状态不一致；设置页和托盘只反映实际注册状态。

显示恢复采用 Win32 `EnumDisplayMonitors` 与 `GetMonitorInfoW` 枚举物理工作区。核心层负责选择距离保存坐标最近的工作区并夹取窗口位置；桌面适配层在启动、移动、尺寸变化和 DPI 变化时调用它。这样显示器被移除后会落到最近可用工作区，同时避开任务栏。

温度首批采用英文 PDH 路径 `\Thermal Zone Information(*)\High Precision Temperature`，失败时回退 `Temperature`。高精度值按十分之一开尔文转换，普通值按开尔文转换；过滤非有限值和不合理范围，多个热区取最高值。界面显示 `ACPI 热区`，不把它描述成 CPU 核心温度。当前电脑实测 `_TZ.TZ00 = 3010`，约 `27.9°C`。NVML 与 LibreHardwareMonitor 桥接仍按 ADR-0005 后续扩展。

## 错误与资源

注册表操作失败时不改变界面开关，并记录错误。显示枚举失败时保留当前位置。温度查询复用现有两秒采样线程，不新增进程或轮询线程；PDH 句柄通过 RAII 关闭。

## 验证

单元测试覆盖温标换算、异常值过滤、最近工作区选择、旧显示器移除、启动命令转义和注册表状态。Windows 11 / 150% DPI 实机验证开机启动开关、任务栏工作区夹取、温度实时值与资源占用。
