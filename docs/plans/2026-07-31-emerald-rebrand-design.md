# 翡翠默认形象与 ZZH 品牌调整

## 范围

默认形象改为 90 帧透明翡翠光球，原动态光球保留为第二个可选项。应用可见名称统一为“ZZH桌面助手”，包括主窗口标题、托盘提示和面板文案。内部配置目录、注册表启动项名称和单实例标识暂不重命名，避免现有设置丢失和升级期间出现双实例。

## 尺寸与动画

收起态窗口由 200×200 缩为 134×134，线性尺寸约减少三分之一；形象绘制区为 128×128。展开面板继续使用 412×640。翡翠帧预处理成单帧 128px 的 10×9 透明精灵图，15 FPS 循环播放，隐藏助手时暂停。原光球继续使用现有 192px 精灵图，两种资源共享同一个帧计时器。

## 配置迁移

配置版本升级到 2，新增 `Emerald` 形象并设为默认。版本 1 只有光球一个隐式选择，因此升级时统一迁移到翡翠形象；迁移后用户仍可在设置页切回原动态光球。未知 UI 索引继续被拒绝。

## Windows 图标

托盘图标使用翡翠首帧。EXE 使用由同一帧生成的 16、24、32、48、64、128、256 多尺寸 ICO，并通过 Windows SDK 资源编译器嵌入，同时写入 ZZH 产品名称和文件描述。
