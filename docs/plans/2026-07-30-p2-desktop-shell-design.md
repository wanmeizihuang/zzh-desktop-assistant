# P2 桌面外壳设计

## 目标与范围

P2 把技术验证窗口变成可长期使用的 Windows 桌面外壳。本阶段覆盖统一生命周期、收起/展开/隐藏/退出、ESC 收起、位置锁定、置顶开关、位置恢复、托盘、单实例、开机启动以及多屏/DPI 恢复。

P1 的 24 小时内存趋势和 ADR-002 最终闸门由用户明确延期。P2 可以继续，但所有性能结论仍是短时基线，不把技术栈决策标记为最终接受。

## 方案选择

采用“核心状态机 + 薄平台适配层”。`app-core` 是应用生命周期和桌面行为设置的唯一事实来源；Slint 只渲染状态并发出用户意图；`apps/desktop` 把意图转换为窗口、托盘和 Windows 系统动作。

未采用纯 Slint 状态，是因为托盘、快捷键和启动恢复都能在 UI 之外改变窗口。也不在第一批引入完整事件总线，因为当前只有一个窗口，事件总线会增加代码和常驻开销，却没有消除实际复杂度。

## 状态与行为

生命周期包含 `Starting`、`Collapsed`、`Expanded`、`Hidden`、`Exiting`。合法转换如下：启动进入收起态；收起态和展开态互相切换；可见态可隐藏；隐藏态可恢复到隐藏前的可见模式；任何非退出态都可进入退出态。退出态不可恢复。

行为设置与生命周期正交：`always_on_top` 默认开启，`position_locked` 默认关闭。锁定后，角色和面板标题栏都不得触发原生拖动。ESC 只在展开态生效并收起面板，不退出应用。关闭按钮与 ESC 使用同一个 `collapse` 转换。

## 配置与故障恢复

本地配置保存版本号、最后有效的物理坐标、置顶和锁定状态。配置位于当前用户的本地应用数据目录。写入使用同目录临时文件、落盘刷新和原子替换；解析失败时保留损坏副本并回退默认值。启动恢复时必须先按当前显示器工作区夹取坐标，避免显示器移除或 DPI 改变后窗口留在屏外。

## 托盘与进程生命周期

托盘菜单和窗口入口共享同一个状态机。菜单首批包含显示/隐藏、展开/收起、始终置顶、锁定位置、开机启动、暂停监控、设置和退出。关闭面板只收起，托盘“退出”才终止事件循环。单实例使用当前用户范围的 Windows 命名互斥体；第二个实例只唤醒第一个实例，不启动第二套监控线程。

## 验证

核心状态转换、非法转换、锁定策略、配置往返、损坏恢复和坐标夹取使用单元测试。窗口行为通过 Windows 11、150% DPI 实机验证：点击、ESC、拖动锁定、置顶切换、隐藏恢复和退出。托盘完成后补充第二实例唤醒以及任务管理器资源回归。
