# 动态形象切换设计

## 目标

设置页提供可扩展的助手形象选择。首个版本只包含默认的“动态光球”，后续可继续增加两个形象。用户选择会写入现有配置文件，并在下次启动时恢复。

## 动画资源

原始资源包含 90 张 512×512 透明 PNG。桌面收起态实际只显示 192×192，因此构建资源使用 10×9、单帧 192×192 的透明精灵图。Slint 只加载一张压缩 PNG，通过裁剪坐标以 15 FPS 循环播放。这样避免每帧读取文件，并将完整解码内存从约 90 MB 降至约 13 MB。隐藏助手时暂停计时器，恢复显示时继续播放。

## 配置与界面

`AppConfig` 增加强类型 `MascotId`，缺少该字段的旧配置自动使用默认光球。Slint 使用整数索引作为 UI 边界，Rust 负责把索引转换成有效形象并持久化，未知索引会被忽略。

设置页顶部增加“助手形象”区，显示实时动画缩略图、名称和选中状态。当前只有一个可点击选项，不显示尚未提供的占位形象。收起态、面板标题和设置预览共用同一帧状态，避免多个计时器造成额外占用。

## 验证

验证配置向后兼容和选择索引边界；运行工作区测试、Clippy、格式检查及 Release 构建。最终检查透明精灵图尺寸与透明通道，并人工确认收起态动画、设置页预览、隐藏暂停和托盘恢复。
